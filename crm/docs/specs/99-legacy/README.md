# Legacy material quarantine

Everything below this directory is historical and untrusted.

Legacy files prove only that certain text existed in a source snapshot. They do
not prove that business rules were approved, technical claims were correct,
tests ran, dependencies existed, or the described system was implemented.

Never move a legacy file directly into `30-approved`. Extract one claim at a
time into a new draft, verify it, present it to the product owner, and follow
the normal approval process.
