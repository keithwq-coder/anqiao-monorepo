# Decisions

`DECISION-LOG.md` records product-owner decisions that affect scope, behavior,
architecture, risk, or authorization. It is not a backlog.

Separate `ADR-*.md` files record reversible technical decisions made under the
AI engineering mandate. An ADR cannot approve product behavior or authorize an
implementation task.

Record:

- the exact decision and date;
- what evidence or question it answered;
- affected SPEC/task ids;
- what it supersedes;
- consequences and remaining unknowns.

Do not record an AI recommendation as a decision until the user explicitly
accepts it.
