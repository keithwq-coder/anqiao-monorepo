# Tasks and file ownership

`TASKS.md` is the index. Each active implementation or review task uses one
file under `active/` based on the task template.

An active implementation task is invalid unless it points to a current approved
SPEC and records explicit implementation authorization. The task must list all
owned files or directories narrowly enough to prevent concurrent edits.

Move completed/cancelled tasks to `closed/`; do not erase their evidence.
