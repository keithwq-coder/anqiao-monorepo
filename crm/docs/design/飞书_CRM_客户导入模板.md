## 📁 使用步骤

### 方法 1：直接复制粘贴到飞书多维表格

1. **打开飞书 App → 创建新的多维表格**
   ```
   首页 → + 新建 → 多维表格 → 空白创建
   ```

2. **重命名表格**
   ```
   点击顶部标题 → 修改为"中科安樵 - 客户管理系统"
   ```

3. **添加第一个数据表（客户信息）**
   ```
   新建视图 → 表格 → 命名为"客户清单"
   
   字段设置：
   - 客户编号：自动编号（手动输入或留空由系统生成）
   - 客户名称：文本（必填）
   - 联系人：文本
   - 联系电话：数字（带区号格式）
   - 公司邮箱：文本或专门邮箱类型
   - 行业分类：单选（创建选项：银行/电信/保险/其他）
   - 客户等级：单选（A 级/B 级/C 级）
   - 跟进状态：单选（未接触/初次接触/方案演示/报价中/谈判中/已成交/已流失）
   - 商机关联金额：数字（设置单位为"万元"）
   - 预计成交时间：日期选择器
   - 负责人：成员选择（需邀请团队成员）
   - 备注：多行文本
   - 下次跟进时间：日期选择器
   ```

4. **逐行粘贴数据**
   ```
   从 Excel 复制一行 → 粘贴到多维表格空行 → 保存
   
   技巧：可以一次性复制多行，分批粘贴
   ```

5. **切换到第二个工作表（跟进记录）**
   ```
   底部"+" → 新建数据表 → 命名为"跟进记录"
   
   字段设置：
   - 记录编号：自动编号
   - 关联客户：关联字段（链接到"客户清单"表）
   - 跟进方式：单选（拜访/电话/会议/邮件/微信）
   - 跟进时间：日期
   - 参会人员：文本或成员选择
   - 沟通内容：多行文本
   - 下一步计划：多行文本
   - 下次跟进时间：日期
   - 附件：文件上传类型
   - 创建时间：自动记录
   ```

6. **导入跟进记录数据**
   ```
   同样从 Excel 逐行粘贴
    
   注意：「关联客户」字段需要选择对应的客户记录
   ```

### 方法 2：通过 Excel 文件导入

1. **将上面的两个表分别保存到独立的 Sheet 中**
   ```
   文件名：飞书_CRM_导入模板.xlsx
   Sheet1: 客户信息表
   Sheet2: 跟进记录表
   ```

2. **打开飞书网页版**
   ```
   https://www.feishu.cn → 登录 → 工作台 → 多维表格
   ```

3. **创建新表格 → 选择「导入 Excel」**
   ```
   上传刚才的 .xlsx 文件 → 映射字段 → 确认导入
   ```

4. **验证数据完整性**
   ```
   检查所有记录是否成功导入
   核对特殊字符和中文是否正常显示
   ```

## 💡 常见问题

**Q1：为什么粘贴后格式错乱了？**
A：确保每个单元格的内容独立，不要跨列粘贴。建议分批粘贴（每次 5-10 行）。

**Q2：电话和手机号格式不对怎么办？**
A：可以在飞书中修改该字段的类型为「电话」或调整数字格式设置。

**Q3：如何批量编辑多个客户的信息？**
A：切换至「看板视图」或「画廊视图」，右键点击卡片即可快速修改字段。

**Q4：发现录错了某条数据如何删除？**
A：选中该行 → 点击「…」→ 选择「删除」。也可以先移到回收站确认后再清空。

**Q5：后续新增的客户如何添加？**
A：直接在表格最后一行手动输入，或使用飞书 App 点击「+ 新建」按钮通过移动端录入。
