# 飞书 CRM - 多人协作与权限配置指南

## 🎯 核心目标

让团队成员通过飞书 App **共同使用**同一个 CRM 系统，实现：

1. ✅ **数据共享** - 所有客户信息统一存储，避免分散
2. ✅ **权限分级** - 不同角色看到不同级别的数据
3. ✅ **协同工作** - 多人同时跟进客户，互不冲突
4. ✅ **AI 分析** - 每个人都能使用 AI 查询自己负责的客户数据

---

### Step 1: 邀请团队成员加入企业（5 分钟）

#### 1.1 获取邀请链接

```markdown
在飞书 PC 端操作：

2. 点击"人员管理" → "邀请成员"
```

### Step 2: 配置多维表格权限（10 分钟）

这是最关键的一步，决定了谁能看到什么数据。

#### 2.1 进入权限管理

```markdown
在 CRM 多维表格中：
1. 点击右上角「…」→ 「权限」
2. 查看当前权限配置
```

#### 2.2 设置字段级权限

为「客户信息表」和「跟进记录表」分别配置：

##### 场景 A：管理员（你）
```json
{
  "role": "管理员",
  "permissions": {
    "查看全部数据": true,
    "编辑所有字段": true,
    "删除记录": true,
    "管理权限": true
  }
}
```

##### 场景 B：销售经理（张三）
```json
{
  "role": "销售经理",
  "permissions": {
    "查看全部数据": false,  // 只能看自己负责的团队
    "编辑所有字段": true,
    "删除记录": false,
    "导出 Excel": true
  },
  "visible_fields": ["客户名称", "联系人", "电话", "状态", "金额"],
  "hidden_fields": ["备注", "负责人邮箱"]
}
```

##### 场景 C：普通销售（李四）
```json
{
  "role": "销售",
  "permissions": {
    "查看全部数据": false,  // 只能看自己负责的客户
    "编辑所有字段": true,
    "删除记录": false,
    "导出 Excel": false
  },
  "filter_rule": "负责人 = 当前登录用户",  // 关键：只显示自己的数据
  "visible_fields": ["客户名称", "联系人", "电话", "状态", "备注"],
  "hidden_fields": []
}
```

#### 2.3 实际操作步骤

1. 在权限页面点击「添加成员」
2. 搜索并选中该成员姓名
3. 选择角色模板（管理员/经理/销售）
4. 自定义权限（如需）
5. 保存配置

**验证：** 用另一个飞书账号登录，确认能看到正确的数据范围。

### Step 3: 配置 AI 助手的个人化视图（15 分钟）

由于使用了**第三方中转站**，我们可以让每个用户看到的 AI 回答只包含他们负责的客户数据。

#### 3.1 修改 AI 提示词（适配用户隔离）

参考之前的 `飞书_CRM_AI_第三方集成.md`，在第 6 步的基础上增加：

```python
# ai_proxy.py - 新增用户识别逻辑

@app.route('/feishu/webhook', methods=['POST'])
def handle_feishu_webhook():
    try:
        data = request.json
        
        # 1. 提取用户 ID（飞书的 user_open_id）
        user_open_id = data.get("sender", {}).get("sender_id", {}).get("open_id")
        
        # 2. 查询该用户负责的客户列表
        user_clients = get_user_responsibility(user_open_id)
        
        # 3. 构建上下文
        context = f"""
        当前用户：{user_open_id}
        负责客户数量：{len(user_clients)}
        客户名单：{user_clients[:5]}  # 最多显示前 5 个作为示例
        """
        
        # 4. 调用 AI（传入个性化上下文）
        messages = [
            {"role": "system", "content": get_system_prompt_with_filter()},
            {"role": "user", "content": context + "\n用户问题：" + message}
        ]
        
        response = call_ai_backend(messages)
        
        return jsonify({...})
    
    except Exception as e:
        print(f"Error: {e}")
        return jsonify({"error": str(e)}), 500

def get_user_responsibility(user_open_id):
    """
    从多维表格查询该用户负责的所有客户
    
    实际实现方法：
    1. 调用飞书 Base API 查询客户信息表
    2. 筛选「负责人」字段等于 user_open_id 的记录
    3. 返回客户名称列表
    
    参考文档：https://open.feishu.cn/document/server-docs/base/read-v4
    """
    # 伪代码示例
    query = {
        "filter": {
            "field": "负责人",
            "operator": "equals",
            "value": user_open_id
        }
    }
    clients = base_api.query(query)
    return [c["客户名称"] for c in clients]
```

## 🔐 安全最佳实践

### 必须做的安全措施

1. ✅ **启用二次验证**
   ```
   飞书后台 → 安全中心 → 开启"强制登录验证码"
   ```

2. ✅ **限制 IP 访问**
   ```bash
   # 如果部署了自己的代理服务器，可以只允许公司内部 IP
   nginx.conf:
   location /ai-proxy/ {
       allow 192.168.1.0/24;  # 仅限内网
       deny all;
   }
   ```

3. ✅ **定期审计日志**
   ```
   每月检查：
   - 谁导出了大量客户数据
   - 哪些记录被频繁修改
   - 异常登录行为
   ```

4. ✅ **离职转交**
   ```markdown
   当员工离职时：
   1. 管理员后台 → 人员管理 → 将该员工账号禁用
   2. 一键转交其名下的所有客户给接替者
   3. 确认转移完成后再彻底移除
   ```

## 💡 常见问题 FAQ

**Q1: 如何让新用户快速上手？**  
A: 准备一份简单的操作手册，包含：
- 如何登录飞书 App
- 如何查看自己负责的客户列表
- 如何使用语音输入跟进记录
- 如何询问 AI 生成日报

**Q2: 可以临时授权外部合作伙伴访问吗？**  
A: 可以，但建议：
- 创建"访客"角色，权限严格控制
- 设置访问有效期（如 7 天）
- 只开放必要的字段（如联系方式）
- 关闭数据导出权限

**Q3: 客户数据会被飞书公开吗？**  
A: 不会。飞书提供了企业级加密和权限控制，只有你授权的人才能看到。建议开启"水印"功能防止截屏泄露。

**Q4: 如何确保 AI 不会越权回答问题？**  
A: 在 AI 提示词中强调"只能回答该用户负责的客户数据"，并在后端代码中过滤掉其他人的信息。

**Q5: 如果团队超过 100 人怎么办？**  
A: 升级到飞书专业版（¥25/人/月），支持更多用户数和更细粒度的权限控制。
