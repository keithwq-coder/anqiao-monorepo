## 🚀 5 分钟快速启动步骤

### 第 1 步：下载并安装飞书（1 分钟）

**手机端：**
```
iOS: App Store 搜索 "飞书"
Android: 应用市场搜索 "飞书" 或访问 https://www.feishu.cn/download
```

**PC 端（可选）：**
```
官网下载安装包或使用网页版 https://www.feishu.cn
```

### 第 2 步：注册企业账号（2 分钟）

1. 打开飞书 App → 点击「立即注册」
2. 输入手机号 → 获取验证码 → 设置密码
3. 创建企业/组织名称（例如：中科安樵）
4. 选择企业类型：中小企业 / 创业公司

### 第 3 步：创建 CRM 多维表格（2 分钟）

方法 A：使用官方模板（推荐新手）
```
1. 在飞书首页点击「工作台」
2. 点击「添加」→ 搜索「销售管理» 或「CRM」
3. 选择任意模板 → 点击「套用模板」
4. 命名："中科安樵 - 客户管理系统"
5. 完成！
```

方法 B：从零自定义创建
```
1. 在飞书文档页面 → 点击「+ 新建」→ 「多维表格」
2. 空白创建 → 重命名为"客户管理系统"
3. 添加以下数据表（详见下方字段配置）
```

```markdown

## 🔧 自动化规则配置（推荐）

### 规则 1：新增客户自动通知

```
触发条件：
- 当「客户信息表」新增一条记录

执行动作：
1. 发送飞书消息给「负责人」
2. 消息模板：
   🎉 新客户入库
   客户名称：{{客户名称}}
   联系人：{{联系人}}
   联系电话：{{联系电话}}
   请及时跟进！
```

### 规则 2：逾期跟进提醒

```
触发条件：
- 每天 9:00 定时触发
- 筛选条件：「下次跟进时间」= 今日 AND「跟进状态」≠ 已成交

执行动作：
1. 在对应负责人的聊天窗口推送消息
2. 消息模板：
   ⚠️ 今日待跟进客户提醒
   
   您有 X 个客户今天需要联系：
   1. {{客户名称}} - {{联系人}} - {{联系电话}}
   2. ...
   
   [点击直达客户详情页]
```

### 规则 3：大额商机预警

```
触发条件：
- 当「商机关联金额」> 50 万元

执行动作：
1. 同时通知「负责人」和「直属上级」
2. 消息模板：
   💰 大额商机预警
   
   客户：{{客户名称}}
   金额：{{商机关联金额}}万元
   预计成交时间：{{预计成交时间}}
   
   请重点关注并及时汇报进展！
```

### 规则 4：连续未跟进预警

```
触发条件：
- 扫描「跟进状态」为「洽谈中」的客户
- 条件：今日日期 - 「最后跟进时间」>= 7 天

执行动作：
1. 将该客户标记为「高风险」
2. 发送提醒给负责人
3. 自动更新字段：风险等级 = 高
```

## 📱 移动端操作速查卡

### 场景 1：快速记录跟进（语音输入）

```
步骤：
1️⃣ 打开飞书 App → 工作台 → 客户管理系统
2️⃣ 找到目标客户卡片 → 点击「添加跟进」
3️⃣ 长按麦克风图标（或语音输入按钮）
4️⃣ 说出完整内容：
   "今天拜访了 XX 公司，张总参加。沟通了产品功能和价格，客户感兴趣但预算有限。
    答应下周一提供优化方案，价格可打折 10%。客户说如果满意就签约，预计 3 个月内。"
5️⃣ AI 自动解析并填充表单
6️⃣ 确认无误 → 提交
```

```

  "我的周报"

## 📞 技术支持与帮助

### 常见问题 FAQ

**Q1：如何备份客户数据？**
A：每月一次导出为 Excel 文件保存到本地 + 飞书云盘

**Q2：团队成员离职怎么办？**
A：管理员后台 → 人员管理 → 转交该员工名下所有客户给其他人

**Q3：AI 分析不准确怎么办？**
A：点击对话框底部的「点踩」按钮反馈 + 完善客户标签 + 提供更多案例文档

**Q4：可以在没有网络的情况下使用吗？**
A：飞书 App 支持离线缓存（最近 3 个月数据），联网后自动同步

**Q5：数据安全如何保障？**
A：企业级加密 + 权限分级（仅自己可见/部门共享/全员公开）+ 操作日志审计
