# 飞书 CRM - 立即开始操作清单

这是给你的**最直接操作步骤**，照着做就行！

---

## 🚀 你的完整流程（共 4 步）

### Step 1: 注册飞书企业账号（5 分钟）

```
手机下载飞书 App → 注册 → 创建企业"中科安樵"
```

**详细步骤：**
1. 在手机应用商店搜索"飞书"并下载安装
2. 打开飞书，点击"注册/登录"
3. 输入你的手机号，获取验证码
4. 设置密码后，会提示"创建企业"
5. 企业名称填写："中科安樵"
6. 企业类型选择："中小企业"或"创业公司"
7. 完成！

**预计耗时：** 3-5 分钟

---

### Step 2: 创建 CRM 系统（10 分钟）

**推荐的模板：** "轻快 CRM"或"销售管理"

**操作步骤：**
```
飞书首页 → 工作台 → +（右上角添加按钮）→ 
搜索"轻快 CRM" → 点击预览 → 套用模板 → 
重命名为"客户管理系统" → 完成
```

**如果找不到"轻快 CRM"：**
搜索任何包含以下特征的模板即可：
- ✅ 有"客户信息表"
- ✅ 能标记 A/B/C 级客户
- ✅ 有"下次跟进时间"字段

**预计耗时：** 8-10 分钟

---

### Step 3: 导入客户数据（可选，5 分钟）

**如果你已经有客户列表：**
```bash
cd d:\Project\中科安樵
python generate_customer_template.py
```

然后用生成的 Excel 文件导入到飞书：
```
打开"客户管理系统" → 点击"+" → "导入数据" → 选择 Excel 文件
```

**如果没有客户数据：**
可以跳过这一步，手动录入几个测试客户就行。

**预计耗时：** 5-10 分钟

---

### Step 4: 邀请同事加入（30 秒/人）

**你在飞书 PC 端操作：**
```
左上角企业图标 → 设置 → 我的企业 → 人员管理 → 
邀请成员 → 输入同事的手机号/飞书账号 → 发送
```

**同事只需要做：**
```
1. 下载飞书 App（如果还没安装）
2. 用你邀请的手机号登录飞书
3. 收到"中科安樵"邀请通知 → 点击"接受"
4. 进入"工作台" → 找到"客户管理系统"
5. 开始使用！
```

**预计耗时：** 30 秒/人

## 🤖 AI 商机扫描器（高级功能）

如果你想启用**后台自动扫描互联网发现商机**的功能：

参考文档：`飞书_CRM_模板选择与配置.md` 中的第三步

你需要：
1. 准备一个服务器（或云服务器）
2. 部署 `ai_merchant_scanner.py` 代码
3. 配置到你的第三方中转站 API Key
4. 设置为每天凌晨自动运行

**预计耗时：** 30-60 分钟（一次性配置）

## 🆘 遇到问题？

| 问题 | 解决方法 |
|------|---------|
| 不会建企业 | 按 Step 1 一步步跟着做 |
| 找不到 CRM | 工作台 → 搜索"客户管理" |
| 同事收不到邀请 | 检查手机号是否正确，重新发一次 |
| AI 不工作 | 先完成前 4 步基础配置，AI 是可选的高级功能 |

## 💡 核心优势

做完这 4 步后，你将获得：

✅ **统一的 CRM 数据库** - 所有人共用同一套客户信息  
✅ **移动端随时访问** - 飞书 App 就能查看/新增/编辑客户  
✅ **权限隔离** - 每个人只能看到自己负责的客户  
✅ **AI 自动扫描商机** - 后台自动发现新机会并推送给销售和主管
