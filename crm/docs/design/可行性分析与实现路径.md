# 中科安樵飞书 CRM 系统 - 可行性分析与实现路径

## 📋 需求理解总结

### 核心诉求
1. **一个飞书企业账号**："中科安樵"供团队共享访问
2. **后台 AI 引擎**：主动扫描互联网发现商机并推送（非聊天助手）
3. **智能分析师**：像销售主管一样思考，提供深度洞察和可执行建议
4. **辅助销售而非替代**：帮助判断、挖掘商机、维护客户、赋能沟通
5. **使用第三方 AI 中转站**：规避额度限制，支持模型切换

#### **Week 3: 深度优化**

##### Day 15-17: 提示词调优

**根据测试结果调整：**

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| AI 回答太泛泛 | 提示词不够具体 | 增加更多示例和要求 |
| 忽略某些信息源 | 搜索关键词不准 | 扩展搜索范围（工商/新闻/招聘等） |
| 判断不准确 | 缺少上下文 | 提供更详细的客户历史背景 |
| 输出格式乱 | 提示词约束不足 | 明确 JSON 结构或 Markdown 规范 |

**实操方法：**
```markdown
每次测试后记录：
1. 用户问了什么问题
2. AI 实际回答了什么
3. 哪里不满意
4. 应该如何改进

然后修改提示词中的对应段落

例如：
【当前】"请帮我分析 XX 公司"
【改为】"请按以下格式分析：
   ① 当前状态（3 句话内概括）
   ② 新发现的信息（每个都要标注来源）
   ③ 这些信息的含义（不要只罗列事实）
   ④ 具体建议（什么时候联系、怎么说）"
```

## 🆘 需要帮助时参考

### 常见问题 FAQ

**Q: 我的技术人员不懂 Python 怎么办？**  
A: 可以先用 No-code 工具（如 n8n/Zapier）搭建简单的自动化，或者找一个兼职开发者帮你写第一版。

**Q: AI 回答总是很烂怎么办？**  
A: 90% 的问题是提示词写得不够好。多给它示例、多给约束、多给上下文，它会慢慢变聪明。

**Q: 团队不愿意用怎么办？**  
A: 先抓一个愿意配合的销售做试点，让他用出效果，然后让大家看到实实在在的收益。

**Q: 如果失败了怎么办？**  
A: 随时可以停掉 AI 代理服务器，回到纯手工模式。飞书 CRM 本身还是有用的，只是少了 AI 功能。
