## 🛠️ 基础搭建阶段（预计耗时：60-90 分钟）

### Step 1: 飞书账号配置（10 分钟）
- [ ] 下载并安装飞书 App（手机）
- [ ] 登录飞书 PC 端网页版
- [ ] 完成企业注册：名称"中科安樵"
- [ ] 设置企业类型（创业公司/中小企业）

### Step 2: 创建多维表格（15 分钟）
- [ ] 进入工作台 → 添加应用
- [ ] 搜索销售管理模板
- [ ] 选择并套用模板（推荐"轻快 CRM"）
- [ ] 重命名为"中科安樵 - 客户管理系统"

### Step 3: 字段配置（20 分钟）
参考【飞书_CRM_配置手册.md】，确认以下字段已配置：

#### 客户信息表
- [ ] 客户编号（自动编号）
- [ ] 客户名称（文本，必填）
- [ ] 联系人（文本）
- [ ] 联系电话（电话类型）
- [ ] 公司邮箱（邮箱类型）
- [ ] 行业分类（单选：银行/电信/保险/其他）
- [ ] 客户等级（单选：A/B/C 级）
- [ ] 跟进状态（单选：7 种状态）
- [ ] 商关联金额（货币，单位：万元）
- [ ] 预计成交时间（日期）
- [ ] 负责人（成员选择）
- [ ] 备注（多行文本）
- [ ] 下次跟进时间（日期）

#### 跟进记录表
- [ ] 记录编号（自动编号）
- [ ] 关联客户（关联字段）
- [ ] 跟进方式（单选：5 种方式）
- [ ] 跟进时间（日期）
- [ ] 参会人员（文本/成员）
- [ ] 沟通内容（多行文本）
- [ ] 下一步计划（多行文本）
- [ ] 下次跟进时间（日期）
- [ ] 附件（文件上传）

## ⚡ 自动化规则配置阶段（预计耗时：30-45 分钟）

### 规则 1：新客户入库通知（优先级⭐⭐⭐）
- [ ] 点击"automations"按钮
- [ ] 新建规则 → 触发条件：新增记录
- [ ] 执行动作：发送飞书消息给负责人
- [ ] 配置消息模板（包含客户详情链接）
- [ ] 保存并测试（手动创建一条新客户）

### 规则 2：逾期跟进提醒（优先级⭐⭐⭐⭐）
- [ ] 新建规则 → 触发条件：定时任务
- [ ] 设置时间：每天 09:00
- [ ] 筛选条件：下次跟进时间=TODAY() AND 状态≠已成交
- [ ] 配置通知消息（列出今日待跟进客户）
- [ ] 设置@负责人功能
- [ ] 保存并等待次日测试

### 规则 3：大额商机预警（优先级⭐⭐⭐⭐⭐）
- [ ] 新建规则 → 触发条件：字段值变化
- [ ] 监控字段：商关关联金额
- [ ] 触发条件：> 50 万元
- [ ] 通知对象：负责人 + 部门负责人
- [ ] 配置预警消息模板
- [ ] 保存

### 规则 4：高风险客户标记（优先级⭐⭐⭐）
- [ ] 新建规则 → 定时触发（每天 18:00）
- [ ] 筛选条件：连续 7 天未跟进的客户
- [ ] 执行动作：自动更新风险等级为"高"
- [ ] 发送挽回建议给负责人
- [ ] 保存

### 规则 5：已成交客户归档（优先级⭐⭐）
- [ ] 新建规则 → 触发条件：跟进状态=已成交
- [ ] 自动创建成交记录到"成交客户库"
- [ ] 发送庆祝消息到销售群
- [ ] 保存

## ⚠️ 常见陷阱与规避方法

### ❌ 陷阱 1：初期数据量过大
**症状：** 第一次就导入 1000+ 条客户  
**后果：** 系统卡顿，难以调试  
**规避：** 先导入 20-50 条测试，确认无误后再批量导入

### ❌ 陷阱 2：字段过于复杂
**症状：** 设置了 30+ 个字段但只用 5 个  
**后果：** 录入负担大，员工抵触  
**规避：** 初期只保留核心字段，逐步扩展

### ❌ 陷阱 3：AI 期望过高
**症状：** 认为 AI 能解决一切问题  
**后果：** 失望弃用  
**规避：** 明确 AI 辅助定位，重要决策仍需人工判断

### ❌ 陷阱 4：自动化配置过多
**症状：** 设置 10+ 个自动化规则  
**后果：** 信息轰炸，干扰正常业务  
**规避：** 分阶段启用，优先核心场景

### ❌ 陷阱 5：缺乏持续维护
**症状：** 上线后不再更新数据  
**后果：** 变成僵尸系统  
**规避：** 制定强制使用规范，纳入绩效考核
