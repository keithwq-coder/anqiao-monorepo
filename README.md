### Step 3: 准备客户数据（根据情况选做）

#### 方案 A：从零手动录入
```
飞书 App → 工作台 → 客户管理系统 → + 新建客户
手动输入现有客户信息
```

#### 方案 B：批量导入（推荐）
```
方法 1：直接使用示例数据
  → 运行脚本：python generate_crm_template.py
  → 得到 Excel 文件：飞书_CRM_导入模板.xlsx
  → 在飞书中导入该文件
  
方法 2：用自己的真实数据
  → 复制【飞书_CRM_客户导入模板.md】中的表头
  → 粘贴到你的 Excel 中并填入实际数据
  → 导入飞书
```

**注意：** 首次建议先使用示例数据测试，熟悉后再导入真实数据

---

### Step 4: 配置 AI 助手（15 分钟）

1. **创建智能体**
   ```
   飞书 PC 端 → 工作台 → 搜索"智能体" → 创建新智能体
   ```

2. **复制提示词**
   ```
   打开【飞书_CRM_AI_提示词.md】
   复制「系统提示词」部分的全部内容
   粘贴到智能体的「系统设定」框中
   ```

3. **关联数据源**
   ```
   在智能体设置中 → 「连接数据」→ 选择你的客户信息表
   授权读取权限
   ```

4. **测试验证**
   ```
   输入测试问题：
   - "查找 XX 银行的联系人"
   - "本周有哪些客户需要跟进？"
   检查回答是否准确
   ```

---

### Step 5: 启用自动化提醒（10 分钟）

参考【飞书_CRM_自动化规则.md】，按优先级配置：

```
优先级 1：新客户入库通知（必须）
  - 触发：新增客户时
  - 效果：负责人即时收到通知
  
优先级 2：逾期跟进提醒（强烈建议）
  - 触发：每天 09:00 自动扫描
  - 效果：推送今日需联系的客户列表
  
优先级 3：大额商机预警（重要）
  - 触发：商关联金额 > 50 万
  - 效果：同时通知负责人和上级
```

## ❓ 常见问题速查

### 安装相关问题
**Q: 飞书能和企业微信互通吗？**  
A: 不能原生集成，但可以通过第三方工具（如集简云）实现单向消息推送。主要建议使用飞书本身。

**Q: 可以不用安装飞书 App 吗？**  
A: 手机浏览器也能访问网页版，但功能受限且体验较差。强烈建议安装 App。

### 数据管理问题
**Q: 数据会被别人看到吗？**  
A: 默认只有管理员可见。可在每个表的「权限」设置中调整为"指定成员可编辑/仅查看"。

**Q: 员工离职后他的客户怎么处理？**  
A: 管理员后台 → 人员管理 → 选择"转交客户" → 指派人 → 一键转移。

**Q: 数据会丢失吗？**  
A: 飞书提供企业级加密和备份。建议每月手动导出一次 Excel 做冷备份。

### 使用技巧问题
**Q: AI 问的问题答不对怎么办？**  
A: ① 检查是否有对应数据 ② 尝试换种问法 ③ 点踩反馈让 AI 学习 ④ 调整提示词权重

**Q: 如何批量修改多个客户的信息？**  
A: 切换到「看板视图」→ 多选卡片 → 批量编辑字段

**Q: 能在电脑上同步查看吗？**  
A: 可以！同一个飞书账号登录多端会自动同步。
