# 双模型接力协议（人只做运送）

人 = 微信：只复制粘贴，不改提示词正文，不替模型做技术决策。  
模型 A = 编排 / SPEC 守卫（写下一跳提示词、验收对方产出）。  
模型 B = 执行（DeepSeek：读仓库、改代码或写回填包相关文件、跑命令）。

## 每跳消息必须含

```
【TO】A 或 B
【FROM】A 或 B
【PHASE】当前阶段名
【TASK】本跳唯一任务（一件事）
【READ】必读文件列表
【DONE 标准】可客观判定的完成条件
【回传】对方必须按固定骨架回传（见下）
【禁止】本跳不许做的事
```

## 执行方（B）回传骨架

```
# RELAY-REPORT
## 状态：DONE / BLOCKED / NEED-OWNER
## 做了什么（文件路径列表）
## 命令与关键输出（摘录）
## 未做 / 阻塞原因
## 给编排方的事实（勿写提示词，只写事实）
## 建议下一跳（一句话，编排方可能改）
```

## 编排方（A）回传骨架

```
# RELAY-PROMPT
## 给执行方的完整提示词
（下面单独一块 ==== 可整段复制）
```
