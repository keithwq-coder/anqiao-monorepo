## 1. 项目目标与业务事实

### 1.1 企业
- 全称：中科安樵（苏州）科技有限公司
- 成立：2023 年，苏州先进技术研究院孵化设立
- 定位表述（唯一对外口径）：**清华同源技术 · 60GHz 毫米波 · 精准健康监测**

### 1.2 营收模式
**卖硬件为主**。官网唯一转化目标 = 获取「设备询价 / 采购意向 / 经销商加盟意向」线索。
不做在线交易、不做服务订阅、不做会员体系。

### 1.3 目标客户（官网只面向 B 端）
| 类型 | 细分 |
|---|---|
| B 端机构 | 高端外资养老、中端民营养老院、政府/社区养老、大健康机构、美业、医疗卫生机构（含基层卫生服务机构） |

## 2. 技术栈与工程约束

### 2.1 技术选型（不得替换）
- **框架**：Next.js（App Router）+ TypeScript
- **样式**：Tailwind CSS（用 §3 设计令牌配置 theme，不要另装 UI 库）
- **数据**：本阶段**新闻等内容全部硬编码**为 TS 数据文件，**不接数据库、不做后台**
- **表单**：Server Action 接收，落地写入本地 JSONL 文件 `data/leads.jsonl`（不接第三方表单服务、不发邮件）
- **构建**：`npm run dev` 可本地跑通即为达标，本阶段不做部署配置

### 2.2 为未来预留（只留结构，不实现）
- 目录预留 `src/app/api/ai/` 空目录 + 一个 `README.md` 说明「未来 AI 服务扩展位」
- 新闻数据层抽象为 `src/data/news.ts` 导出数组 + 类型，未来换数据库只需替换该模块
- **不要**现在就写数据库连接、ORM、admin 登录

### 2.3 安全要求
- 表单 Server Action 必须做输入校验（长度上限、必填、类型），拒绝超长输入
- `data/leads.jsonl` 必须写入 `.gitignore`（含客户线索，不入版本库）
- 表单**无认证保护**属已知状态：本阶段仅本地运行，不暴露公网。若后续部署，需补速率限制与验证码——在 README 中以「⚠️ 部署前必办」标注

#### 5.3.0 数据字段扩展（产品网页组）

`src/data/products.ts` 的 `Product` 类型在保留现有字段基础上，新增以下**可选**字段（向后兼容，缺字段对应 Tab 自动隐藏）：

```ts
export type ProductSpecGroup = {
  groupName: string;                          // 分组名，如"探测参数"
  items: { label: string; value: string }[]; // 键值对
};
export type ProductVideo = {
  title: string;
  url: string;                                // 本地路径或嵌入 URL
  type: "intro" | "installation" | "scenario";
};
export type ProductDocument = {
  title: string;
  url: string;                                // PDF 路径
  type: "manual" | "brochure" | "certificate";
};
export type ProductFAQ = { question: string; answer: string };

// Product 新增可选字段：
deployment?: string[];      // 房间级部署点位：卧室/卫浴/客厅/护理站（区别于 scenes 客户类型标签）
specGroups?: ProductSpecGroup[];   // 优先于 spec 纯文本
videos?: ProductVideo[];
documents?: ProductDocument[];
faqs?: ProductFAQ[];
relatedSlugs?: string[];    // 互补产品 slug（SH100↔BH100 等）
isPlatform?: boolean;      // 安守护平台中枢标记
```

- `spec` 纯文本保留为兜底（specGroups 存在时优先渲染表格）
- 图片仍硬编码于 `images`，不接 CMS
- `relatedSlugs` 驱动"相关产品"Tab，并在 `/solutions` 的设备组合上生成链接（反向入口）
- `isPlatform=true` 的产品在相关产品区标注"云平台中枢"，可视化硬件接入关系

### 5.5 经销商招商 `/dealers`
