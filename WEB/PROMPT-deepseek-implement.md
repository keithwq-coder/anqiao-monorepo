## 五个已实测的坑（计划里已规避，照做别踩回去）

1. **`create-next-app` 拒绝非空目录**（本目录已有 `SPEC.md` 等）。可行做法是先生成到子目录再移出，子目录名不能以点开头。计划 Task 1 有完整命令。

2. **`"use server"` 文件里不能导出非 async 的值**。类型、常量、下拉选项数组放进去会 build 报 `TypeError: Cannot read properties of undefined`。所以计划把它们放在 `src/lib/lead.ts`（Task 11），`src/actions/submit-lead.ts` 里只导出 `async function submitLead`（Task 12）。

3. **本机有 `ALL_PROXY=http://127.0.0.1:7897`**，`curl` 打本地 dev server 会返回 **502**。所有本地冒烟必须写成：
   ```bash
   curl -sS --noproxy '*' http://127.0.0.1:3000/products
   ```

4. **`npx tsx -e "..."` 带 import 会静默无输出**。要跑数据层自检就写成临时 `.ts` 文件再 `npx --yes tsx ./check-tmp.ts`，跑完 `rm` 掉。计划里的自检步都是这么写的。

5. **无 JS 情况下 POST Server Action** 需要回填页面里的 4 个 `$ACTION_*` 隐藏字段并带 `Origin` 头，否则报 `Connection closed.` 或 `formData undefined`。计划 Task 21 给了用 python 抽取隐藏字段再 POST 的完整脚本。**表单验证也可以直接在浏览器里点，同等有效，但必须真做一次并记录结果。**
